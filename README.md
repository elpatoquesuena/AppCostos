# AppCostos

Aplicación Android para costeo de productos de pastelería, con datos guardados localmente en el dispositivo.

## Funciones iniciales
- Registro de insumos y actualización con historial de precios.
- Recetas, rendimiento, presentación y precio de venta.
- Estimación del costo con insumos y mano de obra.
- Parámetros de valor hora y margen de contribución ideal.
- Base de datos local.

## Descargar el APK
1. Abrí la pestaña **Actions** del repositorio.
2. Entrá en la última ejecución de **Build Android APK**.
3. En **Artifacts**, descargá `app-costos-release`.
4. Descomprimí el archivo y abrí el APK en Android para instalarlo.

Primera versión en desarrollo: verificá los cálculos con tus propias unidades y recetas antes de tomar decisiones comerciales.
